## 含义

**动作、过程或结果名词**。词缀可以帮助推测大致含义与词性，但最后应结合句法和上下文确认。

## 形成规则

常把动词变成名词；可能删去词尾 e，或改变词干。

```text
operate → operation
reserve → reservation
inform → information
apply → application
```

## 常见词与关系

- operate → operation
- reserve → reservation
- inform → information
- apply → application

## 例句与解析

> Your application has been approved.
>
> 你的申请已获批准。

application 作主语，has been approved 是现在完成时被动结构。

## 常见误判

> **注意**：不把它当纯拼接公式：apply → application，词干会变化。
