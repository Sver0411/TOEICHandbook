## 含义

**执行者、职业或工具**。词缀可以帮助推测大致含义与词性，但最后应结合句法和上下文确认。

## 形成规则

许多动词可形成表示人或设备的名词。

```text
employ → employer
operate → operator
manage → manager
supply → supplier
```

## 常见词与关系

- employ → employer
- operate → operator
- manage → manager
- supply → supplier

## 例句与解析

> The operator checked the machine.
>
> 操作员检查了机器。

operator 指执行操作的人，operation 指操作或运作。

## 常见误判

> **注意**：部分 -er 表示比较级，如 faster；要根据词根与句法判断。
