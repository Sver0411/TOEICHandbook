## 核心含义

**安装**。用于软件、设备和设施；不是下载本身。

## 常用搭配与结构

- `install software`
- `install equipment`

## 例句与解析

> A technician will install the new security system.
>
> 技术员将安装新的安保系统。

will install 为未来动作；the new security system 是安装对象。没有说安装已经完成，不能改读为已投入使用。

## 词性变化与词族

`installation`

词族帮助连接词义，但每种形式的句法位置不同。名词可作主语或宾语；形容词修饰名词或作表语；谓语位置需要符合时态的动词形式。

## 易混与常见错误

> **注意**：download 只是下载；install 才是安装，顺序需分清。

## TOEIC 场景

**技术服务**。在通知、邮件、对话或说明中，留意这个词描述的是人物、动作、状态还是物品。Part 5 读空格两侧判断词性；Part 7 结合时间、身份和条件定位信息。
