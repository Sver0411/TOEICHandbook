## 不只记中文意思，要看词的结构

词根提供核心概念，前缀常改变方向、范围或否定意义，后缀常改变词性或角色。比如 **employ → employment / employee / employer**，这些词共享雇用的概念，却在句中承担不同工作。

```text
employ（雇用，动词）
├─ employment（雇用 / 就业，名词）
├─ employee（受雇者，名词）
└─ employer（雇主，名词）
```

## 三步读懂一个新词

1. 在句子里判断词性：它在主语、宾语、修饰语还是谓语位置？
2. 看你认识的词根与词缀：它可能与什么动作、状态或角色有关？
3. 把大致含义放回上下文验证。拆词是线索，不能代替确认词义。

## 词缀与句法一起学

| 词 | 词性 | 在句中怎么用 |
| --- | --- | --- |
| operate | 动词 | The company operates stores. |
| operation | 名词 | The system is in operation. |
| operational | 形容词 | The system is operational. |
| efficiently | 副词 | The system operates efficiently. |

## 容易踩的坑

**不是所有词都能机械拼接。** maintain → maintenance，apply → application 都有词形变化；friendly 以 -ly 结尾却常是形容词。把例外连同例句一起记，比背一个过度简化的规则可靠。

## 怎样用在 TOEIC 阅读中

> The new warehouse will improve operational efficiency.
>
> 新仓库将提高运营效率。

operational 修饰名词 efficiency；will improve 是谓语。即使不认识整个短语，也能先定位为“改善某方面的效率”。

## 推荐阅读顺序

先读 [employ](/read/employ/) 与 [employment](/read/employment/)，再看 [-ment](/read/ment/)、[-ee](/read/ee/) 与 [-er / -or](/read/er/)。然后把 [operate](/read/operate/) 与 [operation](/read/operation/) 放到真实句子中比较。
