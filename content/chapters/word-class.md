## 看位置比看翻译更可靠

| 位置 | 常见形式 | 示例 |
| --- | --- | --- |
| 主语 / 宾语 | 名词或名词短语 | The operation began. |
| 名词前 | 形容词、名词作定语 | an efficient system; office equipment |
| 系动词后 | 形容词或名词性补语 | The system is operational. |
| 修饰动作 | 副词 | The system operates efficiently. |
| 情态动词后 | 动词原形 | It can operate. |

## 同一个词可以有多个词性

request 可以作动词，也可以作名词；schedule 可以表示日程，也可以表示安排。不能只凭单词认定结构。比较：**We request information.** 与 **We received a request for information.**

## 词族与词尾只是辅助证据

approve → approval；efficient → efficiency / efficiently。遇到空格时先判断句子缺什么，再选择这个位置可用的形式。[形容词与副词](/read/adjectives-adverbs/) 有更多对照。

## -ing 与 -ed 不自动等于谓语

> The revised schedule includes training sessions.
>
> 修改后的日程包括培训课。

revised 修饰 schedule；training 修饰 sessions；includes 才是句子的完整谓语。

## 多音节词的比较

efficient → more efficient；careful → more careful。不要把比较级重复为 more cheaper。变化幅度读法见 [比较与数量变化](/read/comparisons/)。

## 阅读中的小检查

找出完整谓语；划定名词短语；识别修饰对象；最后确认词义是否适合场景。词性和含义需要同时满足。
