## 核心结构

```text
submit + 文件 + to + 审核方；submit + 文件 + by + 截止时间
```

## 常用搭配

- `submit a report`
- `submit an application to the committee`

## 例句与解析

> Please submit your report to the manager by Friday.
>
> 请在周五之前向经理提交报告。

report 是提交对象；to the manager 是接收方；by Friday 是截止时间。

## 常见错误

> **注意**：submit → submitted/submitting 双写 t；by 与 until 含义不同。

## TOEIC 应用

在邮件、流程说明和通知中，把动词与它后面的结构一起理解。Part 5 不只考单词含义，也会区分后面应接名词、介词、动名词还是不定式。

## 迁移到自己的表达

保留上面例句的动词结构，只替换人物、文件、时间或地点。替换后检查：宾语有没有遗漏？介词后是否需要动名词？时间短语是否表达了真正想说的关系？
