## 核心结构

```text
request + 名词；request that + S + 动词原形
```

## 常用搭配

- `request information`
- `request assistance`
- `request that staff arrive early`

## 例句与解析

> Please request assistance at the reception desk.
>
> 请在接待处请求帮助。

assistance 是 request 的直接宾语。正式要求从句常使用原形或 should + 原形。

## 常见错误

> **注意**：作动词不写 request for information；名词 a request for information 正确。

## TOEIC 应用

在邮件、流程说明和通知中，把动词与它后面的结构一起理解。Part 5 不只考单词含义，也会区分后面应接名词、介词、动名词还是不定式。

## 迁移到自己的表达

保留上面例句的动词结构，只替换人物、文件、时间或地点。替换后检查：宾语有没有遗漏？介词后是否需要动名词？时间短语是否表达了真正想说的关系？
