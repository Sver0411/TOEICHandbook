## 结构

```text
if + present, will + V；if + past, would + V；if + had done, would have done
```

## 使用场景

条款、优惠条件、假设预算，以及对已发生事情的反思。

## 时间关键词与判断线索

if / unless / provided that；真实未来条件从句通常不用 will。

关键词提供线索，最终要看句子表达的时间关系、主干结构和说话者关注的重点。

## TOEIC 例句与解析

> If you order today, we will deliver the equipment tomorrow.
>
> 如果今天下单，我们明天会配送设备。

order 在 if 从句用一般现在时，主句 will deliver 表未来结果。

## 常见错误

> **注意**：把 if 从句和主句都机械写 will；unless 后再加多余否定。

## 对照与延伸

If we had received the form earlier, we could have processed it yesterday. 表未实现的过去条件。
